模型与两个朴素基线

留出最后 6 个月（2024-07 至 2024-12，141 个样本）做时间切分验证。 同时给出 lag-1 与 3 月滚动均值两个基线，避免只报一个好看的数。

一个诚实的结论

梯度提升树相对 3 月滚动均值基线更好，但在这 6 个月上仍略逊于 lag-1 基线（MAE 3673 对 3334）。 这说明「用车企上一个月的销量」本身已经很强，模型的价值要靠在更长周期、更多车型上的稳定性来证明，而不是只比一个基线。

Implementation

系统怎么搭起来的

后端 FastAPI + scikit-learn，前端原生 HTML / CSS / JS，不依赖 CDN；从清洗、特征、训练到预测和展示是一条完整链路。

  1. 01数据清洗车型名称、月份、能源类型、级别与价格区间标准化，641 条记录进入面板。
  2. 02特征工程时间特征、lag 1/3/6/12、滚动均值与标准差、同比环比，共 20 维特征。
  3. 03模型训练GradientBoostingRegressor：220 棵树、学习率 0.045、深度 3、子采样 0.92，目标取对数。
  4. 04推理服务递归多步预测：把上一步预测写回历史，再构造下一步特征；FastAPI 暴露 6 个接口。
  5. 05前端展示原生 JS 绘制历史/预测曲线与表格，零外部依赖，可离线部署。
