01

概览

电池数量有限、工况各不相同，预测未来容量保持率并不只是「换一个更强的模型」的问题。 本文固定函数类、损失函数与停止规则，只改变参数估计流程，检验估计路径本身能否带来可重复的预测改善。

三条路径共享同一个 661 参数函数：JOINT 用 Adam 联合更新全部参数； WARMSTART 先做一次解析条件求解，再联合训练； PROFILE 在每轮迭代中持续把线性参数块写回条件最优解，只对外层交互参数做梯度更新。 由于输入信息、标签定义与数据划分完全一致，三者之间的差异只能来自估计过程。

阅读方式

本文不主张 Gaussian-KAN 本身更优，而是把「初始化」「条件求解」与「验证集选择」拆开， 看它们各自贡献了什么、又在哪些数据域失效。因此结论以逐电池、逐配置的配对比较为主， 而不是只报一个平均分。

02

三个问题

  1. 在相同的训练预算与停止规则下，估计流程的变化是否足以改变预测误差？
  2. 如果改变，增量来自一次解析初始化，还是来自迭代过程中的持续条件求解？
  3. 这种收益能否跨数据集、跨电池保持，还是只在开发集上成立？

问题 2 需要用 WARMSTART 作为中间对照才能区分：JOINT 与 PROFILE 的比较同时改变了两件事——是否解析初始化，以及是否持续约束条件最优。

03

方法：固定的函数，变动的估计

输入是重采样后的历史电压、电流与温度曲线统计量：4 个历史分支 × 3 条曲线 × 5 个统计量，得到 60 维特征。 每个标准化坐标配 8 个等距 Gaussian 基中心（σ = 0.8，名义范围 [−3, 3]），设计向量由 60 个线性坐标与 480 个基值拼接而成。模型由加性主效应、去对角二次交互与不惩罚截距组成：

Model F(z) = D(z)·w + b + I(z; u, v)
I(z; u, v) = (uᵀz)(vᵀz) − Σj ujvjzj²

固定交互参数 u、v 后，线性块的条件解是一个带二次惩罚的严格凸子问题。实现上对去中心化的设计矩阵 只做一次 float64 薄 SVD，并缓存线性映射，因此每轮条件求解的代价是 O(np)，而不需要重复分解：

Conditional solve w* = (DcᵀDc + nαI)−1 Dcᵀrc，  b* = r̄ − D̄w*
α = 0.001，交互参数惩罚 β = 0.0001；分母 λ² + nα 恒正，零奇异值对应滤波系数为零。
JOINT联合梯度训练
共同初始化 Adam 更新 w, b, u, v 验证集选 checkpoint
WARMSTART一次解析初始化
条件求解 w, b 以解为初值联合训练 验证集选 checkpoint
PROFILE持续条件求解
每轮按当前 u, v 求条件解 对 u, v 做 Adam 更新 写回条件解 · 复用缓存映射

三个数据域分别按物理电池隔离：Oxford 用于方法开发与估计策略比较（8 块电池，H = 100 循环）， NASA 与 SDU 用于固定方案的留出评价（4 块测试电池 / 468 个目标；19 块测试电池 / 501 个目标）。 参数在各域训练集上重新估计，不做零样本迁移。

04

结果

Oxford 开发集上，三条路径的主分数依次为 0.023988、0.011984 与 0.011700。 仅改变估计流程，开发误差就下降了约一半；其中 WARMSTART 一次解析初始化 已经取得 50.04% 的降幅，PROFILE 在此基础上再降 2.37%。

主分数为电池等权的标准化误差，越低越好。差额比 (SJOINT − SWARMSTART) / (SJOINT − SPROFILE) = 97.69%，表示一次解析初始化拿到了大部分可观察的改善—— 但这是估计流程之间的代数比较，不是初始化的因果贡献率，因为 WARMSTART 同时包含后续训练与验证集选择。

跨数据域的固定方案评价给出了不同的图景。NASA 上持续条件求解的增量最大： PROFILE 的测试电池等权 RMSE 为 0.033003，相对 JOINT 降低 41.58%，并且在全部 4 块测试电池上都有改善。SDU 的 19 块测试电池上， PROFILE 的宏 RMSE 为 0.022633，相对 JOINT 降低 57.40%。

05

结论与边界

这些结果支持的判断是：在明确的训练预算与停止规则下，估计路径是影响预测结果的重要因素， 而且它的收益随数据域与电池而变化。它们不支持「该方法对任意电池、任务或化学体系普遍更优」。

  • 条件最优不等于跨域可靠。NA-ion 探索性评价中，PROFILE 的宏 RMSE 为 0.129883， 最差电池达到 1.424789——异常输出主要来自二次交互分支，而对应输入已远离训练分布。
  • 平均收益不等于多数电池更好。Oxford 的 8 个配置—电池项中 PROFILE 只有 5 项改善； 相对线性交互对照组也只有 3 项改善、5 项退化。
  • 结构归因受模型规模约束。Gaussian 版本比线性交互控制多 480 个可拟合系数， 因此不能把差异完全归给表示本身。
  • 排名限定在共同停止预算内。NASA 的 JOINT 有 4 次、SDU 有 3 次训练触及 180 轮上限， 不能据此认定它们充分优化后仍然更差。
最有价值的一条

正则化条件解的数值残差（PROFILE 约 10⁻¹² 量级）只能说明子问题被准确求解， 不能替代跨电池、跨数据域的可靠性验证。两类证据要一起报。
